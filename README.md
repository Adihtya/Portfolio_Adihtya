## 05 — GETTING STARTED

Want to explore the source code or run the portfolio locally?

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git

### 01. Clone the repository

```bash
git clone https://github.com/Adihtya/Portfolio_Adihtya.git
```

### 02. Enter the project directory

```bash
cd Portfolio_Adihtya
```

### 03. Install dependencies

```bash
npm install
```

### 04. Start the development server

```bash
npm run dev
```

Open the local development URL displayed in your terminal.

Usually:

```text
http://localhost:5173
```

### 05. Build for production

```bash
npm run build
```

### 06. Preview production build

```bash
npm run preview
```
